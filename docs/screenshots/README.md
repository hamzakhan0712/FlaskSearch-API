# Screenshots

The table at the top of the project README expects these four files in this folder:

| File | What to capture |
| --- | --- |
| `home.png` | http://localhost:9090 showing the full play list |
| `search.png` | The same page after searching, with matching rows in the table |
| `add-play.png` | The Add Play modal open over the list |
| `api-plays.png` | The raw JSON from http://localhost:9090/api/plays |

PNG, captured at a normal browser width. Replace these placeholders and the README table picks
them up with no edits.
